# Girl hero sheets — image prompts

Each hero gets a second look: a girl version with the **same outfit, colors,
weapons and pose list** as the existing sheet, so she reads instantly as the same
hero class. Stats and rules don't change; the game just swaps the art (players
pick Girl / Boy under the hero card; a fresh game shows a mix).

## How to make one

1. In your image tool, attach the existing sheet as the reference:
   `art/references/heroes/H_<HERO>.webp` (or the original PNG in Drive).
2. Paste that hero's prompt below. The shared rules are already included in each.
3. Save the result to the Drive `heroes` folder as `<hero>-girl.png`
   (e.g. `archer-girl.png`). I'll crop the front pose, add the Flow input, and
   the existing hero video prompt works for her with one line changed.

**Shared rules (already in every prompt):** same age as the original (young,
cute chibi proportions), practical armor and clothing with the same coverage as
the original, nothing glamorous or grown-up. What makes her read as a girl at
small size: face shape, eyes, and a hairstyle that shows (braid, ponytail,
bun). For full helmets, the visor is raised or a braid shows under the helmet.

Suggested order: the six that a fresh game shows as girls first (Archer, Rogue,
Monk, Battlemage, Berserker, Hunter), then the rest.

## If a result is off

- **Looks like a different class:** add "keep the outfit identical to the reference; only the face and hair change".
- **Looks older or glamorous:** add "same young age as the reference, simple cute face, no makeup".
- **Layout drifts:** add "copy the exact pose layout and label positions from the reference sheet".
