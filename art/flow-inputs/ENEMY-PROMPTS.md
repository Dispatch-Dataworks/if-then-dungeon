# Flow prompts — enemy card loops

Same routine as the heroes (see `PROMPTS.md`): add the enemy's image from this
folder as an **ingredient / reference**, set **16:9**, paste its prompt, and save
the clip to the Drive `enemies` folder named after the enemy (`Goblin Scout.mp4`
or `E_GOBLIN_SCOUT.mp4`, either is fine).

Enemies get the same calm idle loop as heroes, but a touch more menace: they look
toward the viewer, and each background hints at where that enemy lives. Kept
PG for ages 10–15: no blood, no gore, nothing jump-scary.

All 13 enemies are covered. The `unassigned-bugbear-thug` prompt at the end is
optional and no longer needed for the Orc Brute.

## If a result is off

Same fixes as the heroes: "match the reference image exactly" if the design
drifts, "almost still, very subtle" if it moves too much, "small in frame, wide
shot" if it's cut off. For the Spider and Hound, add "all legs visible" if feet
get cropped.
