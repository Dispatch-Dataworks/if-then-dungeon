# Flow prompts — hero card loops

One image + one prompt per hero. The images in this folder are the front pose
from each concept sheet, on white, 1024×1024.

## How to run one (phone)

1. In Flow, start a new video using the mode that takes your image as an
   **ingredient / reference** (not "first frame" — the white background would
   stay white).
2. Add the hero's image, e.g. `H_SWORDSMAN.jpg`.
3. Set **16:9** landscape. Fast/cheaper quality is fine for a first pass.
4. Paste that hero's prompt block below and generate.
5. Save the clip you like to Drive → `If then Dungeon/assets/videos/`, named by
   ID (`H_SWORDSMAN.mp4`). Raw clip is fine; trimming, looping, cropping to the
   card shape and compressing happen on my side.

Every prompt keeps the hero in the **centre third** of the frame, because the
card crops the 16:9 clip down to 5:4.

### H_SWORDSMAN — Blademaster

```
Animate the character from the reference image as a calm, seamlessly looping idle animation for a fantasy game card. Keep the character's exact design, colors, proportions and cute chibi style. A young swordsman in a rounded steel helmet, steel pauldrons and breastplate over brown leather, a blue scarf and short blue cape, holding a short steel sword low in the right hand. The swordsman stands centered in the frame, facing the camera, full body visible with clear space above the helmet and below the boots. Idle motion: slow steady breathing, a small shift of weight from foot to foot, the sword tip dips slightly then rises back to guard, the blue cape sways gently. Background: a dark torch-lit stone dungeon hall, softly out of focus, warm firelight flickering across the armor. Static camera, no zoom, no pan, no cuts. Subtle motion only; the final frame matches the first frame. No text, no UI, no extra characters.
```

## If a result is off

- **Character changes design:** add "match the reference image exactly" at the
  start, or try the Frames mode with this image as first frame (background will
  stay white; I can key it out later).
- **Too much movement / camera drifts:** add "almost still, very subtle".
- **Hero too big or cut off:** add "small in frame, wide shot".
